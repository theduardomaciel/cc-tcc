\begin{abstract}
    Cross-platform frameworks reduce code duplication, but they usually cost performance and resource usage. Many also render their own interface or embed a WebView, which compromises fidelity to each operating system's design system. Maintaining one native version per platform avoids these costs but multiplies codebases. This work proposes generating native projects for Windows (WinUI~3) and macOS (SwiftUI) from a single declarative source, without a rendering layer of its own. It aims to evaluate whether the generated applications achieve performance comparable to applications handwritten with each platform's official tools, and to what extent the single source can express each system's interface components. To this end, an experiment compares three versions of two reference applications (handwritten native, generated and self-rendered) in response time, memory, CPU, storage and visual similarity.

    \keywords{cross-platform development; native user interfaces; code generation; transpilation; performance;}
\end{abstract}
