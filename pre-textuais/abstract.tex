\begin{abstract}
    Cross-platform frameworks reduce code duplication, but often introduce performance and resource overhead. Many also render their own user interfaces or embed a WebView, which can compromise fidelity to each operating system's native design system. Independent native implementations avoid these limitations but entail separate codebases. This work proposes generating native projects for Windows (WinUI 3) and macOS (SwiftUI) from a single declarative source, without implementing its own rendering layer. It aims to evaluate whether the generated applications achieve performance comparable to that of applications developed manually using each platform's official tools, and to what extent a single source can adapt interfaces to the design conventions and patterns of each operating system. To this end, an experiment compares three implementations of two reference applications (manually developed native, code-generated native, and framework-rendered) in terms of response time, memory consumption, CPU usage, storage footprint, and visual similarity.

    \keywords{cross-platform development; native user interfaces; code generation; transpilation; performance;}
\end{abstract}
